# Patches

shadPS4/GoldHEN-format XML patch files for the game's executable go here (`scripts/patches.py`
compiles the selected ones into `out/patches.bin`). `Deadpool.xml` holds the frame rate unlock (off by default; `BB_FPS=uncap` turns it on). Patches name
the title (`CUSA03528`) and version (`01.00`) they are for; files for other titles are skipped.

# Patches

shadPS4/GoldHEN-format XML patch files for the game's executable go here (`scripts/patches.py`
compiles the selected ones into `out/patches.bin`). None are bundled for Deadpool: the port's own fixes (the frame rate unlock) are built into `scripts/patches.py` and switched by settings, not listed here. Patches name
the title (`CUSA03528`) and version (`01.00`) they are for; files for other titles are skipped.

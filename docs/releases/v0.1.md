**Deadpool PS4 Port v0.1**

This is a first test release of a native Windows port of Deadpool for PS4 (EU, CUSA03528, version 01.00). **It contains no game files.** You need your own dump of the game, and the launcher will ask for its folder.

**What's in it**
- Native PC port with a Vulkan renderer
- Main menu runs at 30 FPS. Gameplay and the pause menu are unlocked, and the launcher's FPS limit setting caps them.
- Graphics fixes: broken geometry, missing title-screen UI, and glowing lights now hidden properly behind walls
- Launcher: pick the game folder, settings, controller setup (player 1), log viewer
- Controller only. Keyboard and mouse are turned off until the official PC controls are known.

**Known limits**
- Ultrawide isn't supported yet.
- Cutscenes haven't been tested at unlocked frame rates.

**Install:** unzip, run `Deadpool-PS4-PORT.exe`, choose your game dump's folder, then press Play.
